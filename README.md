# RecordU

看到让你咯噔一下的内容，5 秒记下你自己的话。每周回顾，积累成属于你的认知清单。

Chrome 扩展（Manifest V3），帮助你在浏览网页时快速捕获阅读感触，并在原页面高亮标注，方便日后回顾与筛选。

## 功能

- **选区捕获** — 选中页面文字后，点击浮动按钮或右键菜单，写下你的感触
- **快捷键** — `Alt+S` 打开快速捕获弹窗
- **原文高亮** — 保存后原文自动高亮；再次打开同一页面时自动恢复，点击高亮可查看和编辑你的感触
- **回顾页** — 待回顾队列 / 按网站浏览，支持日期筛选与删除整理
- **导出 Markdown** — 一键导出当前筛选结果，便于归档或二次整理

## 安装

1. 克隆或下载本项目
2. 打开 Chrome，访问 `chrome://extensions/`
3. 开启右上角 **开发者模式**
4. 点击 **加载已解压的扩展程序**，选择项目根目录

安装完成后，浏览器工具栏会出现扩展图标。

## 使用

### 方式一：选区捕获（推荐，支持高亮）

1. 在任意网页上选中一段文字
2. 点击选区旁的橙色引号浮动按钮
3. 在弹出的面板中写下你的感触，点击 **保存**

保存后，选中的原文会立即高亮。之后再次访问该页面，高亮会自动恢复；**点击高亮**可查看并编辑你的感触。

高亮用 **TextQuote（原文 + 前后文）** 定位，失败时再回退 **TextPosition（全文偏移）**；跨标签选区会按文本节点分片包裹，避免拆坏 DOM。动态页面会通过 MutationObserver 与 `history` 变化持续尝试恢复。

> 高亮依赖保存时的选区锚点（`anchor`）。通过弹窗直接记录、未选中文字时不会生成高亮。若页面正文被大幅改写，高亮可能无法恢复。
>
> **不兼容旧版数据**：旧记录里的 `context` / `prefix` / `suffix` 字段已废弃。升级后请先导出备份，再清空本地数据或重新捕获，旧条目不会再显示页面高亮。

### 方式二：快捷键 / 弹窗

按 `Alt+S` 或点击扩展图标，打开快速捕获弹窗。适合快速记下一闪而过的想法，会关联当前页面标题和 URL，但不包含原文选区。

### 方式三：右键菜单

选中文字后，右键选择 **捕获感触**，效果同方式一。

### 回顾与整理

点击弹窗中的 **回顾 ↗**，或在扩展内打开回顾页。默认进入**本周待回顾**队列：

| 功能 | 说明 |
|------|------|
| 待回顾 | 左列表右详情，逐条浏览；不需要的条目可删除 |
| 网站 | 左侧按站点聚合，右侧展示该站所有感触 |
| 本周 / 更早 / 全部 | 日期范围筛选 |
| 导出 | 导出当前模式与日期范围下的 Markdown |

**回顾页快捷键**（待回顾模式）：

| 按键 | 作用 |
|------|------|
| `j` / `↓` | 下一条 |
| `k` / `↑` | 上一条 |
| `d` / `Backspace` | 删除当前条目 |
| `o` | 在新标签页打开原文链接 |

建议每周花约 20 分钟回顾：把还让你有感觉的留着，其余删掉。

## 项目结构

```

├── manifest.json          # 扩展配置
├── background.js          # 后台服务：存储、右键菜单、消息路由
├── content.js             # 内容脚本：选区捕获、高亮、悬浮提示
├── popup.html / popup.js  # 快速捕获弹窗
├── review.html            # 回顾页入口
├── review/
│   ├── main.js            # 回顾页入口与路由
│   ├── state.js           # 模式、日期范围、焦点状态
│   ├── queue-view.js      # 待回顾队列视图
│   ├── browse-view.js     # 按网站浏览视图
│   ├── split-view.js      # 左列表 + 右详情布局
│   ├── keys.js            # 键盘快捷键
│   ├── export-md.js       # Markdown 导出
│   └── action-icons.js    # 操作按钮图标
├── shared/
│   ├── api.js             # 与 background 通信、存储读写
│   ├── captures.js        # 捕获记录工具函数
│   ├── dom.js             # DOM 工具
│   ├── time.js            # 日期与时间格式化
│   └── favicon.js         # 回顾页站点图标
├── modal.js               # 确认对话框
├── styles.css             # 弹窗与回顾页样式
└── icons/                 # 扩展图标
```

## 数据存储

所有感触保存在浏览器本地（`chrome.storage.local`），不会上传到任何服务器。卸载扩展或清除浏览器数据会导致记录丢失，重要内容请定期通过 **导出 Markdown** 备份。

## 权限说明

| 权限 | 用途 |
|------|------|
| `storage` | 本地保存捕获记录 |
| `contextMenus` | 右键「捕获感触」菜单 |
| `activeTab` | 获取当前标签页信息 |
| `<all_urls>` | 在任意网页注入内容脚本，实现选区捕获与高亮 |

## 开发

本项目为纯 JavaScript，无构建步骤。修改代码后，在 `chrome://extensions/` 页面点击扩展的 **重新加载** 即可生效。

回顾页和弹窗需在已加载的扩展环境中打开（通过扩展图标或 `review.html`），不能单独用静态服务器预览完整功能。
