# RecordU

![RecordU](icons/icon128.png)

看到让你咯噔一下的内容，5 秒记下你自己的话。每周回顾，积累成属于你的认知清单。

Chrome / Chromium 扩展（Manifest V3），帮助你在浏览网页时快速捕获阅读感触、标记单词，并在原页面高亮标注，方便日后回顾与筛选。

## 功能

- **选区捕获** — 选中页面文字后，点击浮动按钮 **i**（想法）或右键菜单，写下你的感触
- **标记单词** — 选区旁点 **w**，自动用大模型查询音标与中文释义；该词会在**所有网站**自动高亮
- **单词级匹配** — 每个单词可单独设变体/精准匹配，优先级高于全局设置
- **截图批注** — 框选页面区域截图后写下感触（适合 PDF、图表等无法划词的页面）
- **快捷键** — 快速捕获：Windows/Linux `Alt+S`，Mac `⌥S`（Option+S）；截图批注：Windows/Linux `Alt+Shift+S`，Mac `⌥⇧S`（Option+Shift+S）
- **原文高亮** — 文字感触保存后原文自动高亮；可设填充或下划线；再次打开同一页面时自动恢复，点击高亮可查看和编辑
- **单词高亮** — 已标记单词在任意网页全文匹配高亮；可设填充或下划线；默认支持英语词形变体；点击可查看释义；可标记「已学会」，学会后不再高亮
- **高亮黑名单** — 设置中指定域名列表，这些站点及其子域不显示感触与单词高亮（捕获仍可用）
- **回顾页** — 待回顾（按时间 / 按网站）、单词（列表 / 试题）；支持日期筛选、编辑与删除；已学会单词带视觉标记
- **词汇练习** — 试题列表可「生成试卷」：选题量与英/中题干方向；大模型出语境填空、用法辨析、场景连线（会利用备注与原文语境）；历史试卷可再开与回顾
- **设置** — 左右分栏：高亮（含匹配与黑名单）、大模型（含思考程度）、提示词、数据备份
- **导出 Markdown** — 一键导出当前筛选结果，便于归档或二次整理（不含单词列表与截图文件）

## 安装

1. 克隆或下载本项目
2. 打开 Chrome（或夸克等 Chromium 浏览器），访问扩展管理页
3. 开启 **开发者模式**
4. 点击 **加载已解压的扩展程序**，选择项目根目录

安装完成后，浏览器工具栏会出现扩展图标。

## 使用

### 方式一：选区捕获（推荐，支持高亮）

1. 在任意网页上选中一段文字
2. 选区旁出现两个浮动按钮：**i**（记下感触）与 **w**（标记单词）
3. 点 **i**，在面板中写下你的感触，点击 **保存**

保存后，选中的原文会立即高亮。之后再次访问该页面，高亮会自动恢复；**点击高亮**可查看并编辑你的感触。

高亮用 **TextQuote（原文 + 前后文）** 定位，失败时再回退 **TextPosition（全文偏移）**；跨标签选区会按文本节点分片包裹，避免拆坏 DOM。动态页面会通过 MutationObserver 与 `history` 变化持续尝试恢复。

> 高亮依赖保存时的选区锚点（`anchor`）。通过弹窗直接记录、未选中文字时不会生成高亮。若页面正文被大幅改写，高亮可能无法恢复。
>
> **PDF 预览页**：浏览器内置 PDF 查看器无法监听划词。请用 **截图批注**（Mac：`⌥⇧S`，其他：`Alt+Shift+S`），或选中后右键「记下感触」（若菜单可用）。
>
> **不兼容旧版数据**：旧记录里的 `context` / `prefix` / `suffix` 字段已废弃。升级后请先导出备份，再清空本地数据或重新捕获，旧条目不会再显示页面高亮。

### 方式二：标记单词

1. 选中要学的单词或短语
2. 点击浮动按钮 **w**
3. 浮层自动请求大模型，展示**音标**与**翻译**（并预填备注）；可改匹配规则（跟随全局 / 变体 / 精准）后保存

首次使用请到回顾页 **设置 → 大模型** 填写 DeepSeek（或兼容端点）API Key。Key 仅存本机。查词/出题提示词可在 **设置 → 提示词** 自定义；翻译提示词须含 `{{word}}`，并期望返回 JSON `phonetic` / `translation`。

该词会在**所有 http(s) 页面**按词匹配并高亮（拉丁词整词、大小写不敏感；中日韩等按精确子串）。单词级匹配优先于全局设置。再次标记同一词会更新字段，不会重复条目。回顾页「单词」可编辑音标、翻译、备注、匹配规则或删除。在网页编辑浮层或回顾页可将单词标为「已学会」：学会后不再页面高亮，回顾列表仍保留并显示「已学会」标签（可撤销）。

### 方式三：截图批注

1. 按快捷键（Mac：`⌥⇧S` / Option+Shift+S；Windows/Linux：`Alt+Shift+S`），或打开弹窗点击 **截图批注**
2. 拖拽框选页面区域，松手后自动截取
3. 写下感触并保存

截图以 JPEG 压缩后存入本地 IndexedDB，回顾页可查看缩略图。截图批注**不会**在原页恢复高亮框。

### 方式四：快捷键 / 弹窗

按快捷键（Mac：`⌥S` / Option+S；Windows/Linux：`Alt+S`）或点击扩展图标，打开快速捕获弹窗。适合快速记下一闪而过的想法，会关联当前页面标题和 URL，但不包含原文选区。

### 方式五：右键菜单

选中文字后，右键选择 **记下感触**，效果同方式一的感触捕获。

### 回顾与整理

点击弹窗中的 **回顾 ↗**，或在扩展内打开回顾页。默认进入本周队列：

| 功能 | 说明 |
|------|------|
| 待回顾 | 顶栏入口；其下可切换 **按时间**（左列表右详情）/ **按网站**（左站聚合右条目） |
| 按时间 / 按网站 | 待回顾的两种展示方式 |
| 单词 | 左侧：**单词列表** / **试题列表**。列表为按日网格；试题可生成练习卷（语境填空 / 用法辨析 / 场景连线，参考备注与原文） |
| 设置 | 左侧菜单：高亮（颜色/风格、单词匹配、黑名单）、大模型（Base URL / Model / API Key、思考程度）、提示词（翻译 / 出题）、ZIP 备份 |
| 本周 / 更早 / 全部 | 日期范围筛选（仅待回顾显示） |
| 导出 | 导出当前展示与日期范围下的 Markdown（截图条仅标注「截图批注」，不内嵌图片；不含单词） |

**回顾页快捷键**（待回顾·按时间 / 单词）：

| 按键 | 作用 |
|------|------|
| `j` / `↓` | 下一条 |
| `k` / `↑` | 上一条 |
| `e` | 编辑当前条目 |
| `l` | 切换「已学会」（仅单词） |
| `d` / `Backspace` | 删除当前条目 |
| `o` | 在新标签页打开原文链接 |

建议每周花约 20 分钟回顾：把还让你有感觉的留着，其余删掉。

## 数据存储

感触、截图、单词与试卷保存在浏览器本地 **IndexedDB**（扩展源）；高亮颜色、匹配规则与大模型配置（含 API Key）保存在 **chrome.storage.local**。不会上传到任何服务器。查词与出题请求由扩展后台直接发往你配置的 LLM 端点。首次启动会把旧版 `chrome.storage.local` 中的捕获数据自动迁入 IndexedDB。

**卸载扩展**、清除扩展站点数据，或换路径加载导致扩展 ID 变化时，本地数据会丢失。同一扩展 ID 下「重新加载」通常不会丢数据。重要内容请到回顾页 **设置 → 数据备份** 下载 ZIP（`manifest.json` + `screenshots/` + `favicons/` 图片文件与设置）；恢复前会清空当前本地数据并以备份为准。页头 **导出** Markdown 仍只作可读文本归档（不含截图文件与单词列表）。

## 权限说明

| 权限 | 用途 |
|------|------|
| `storage` | 全局设置、迁移标记与旧数据迁出 |
| `contextMenus` | 右键「记下感触」菜单 |
| `activeTab` | 获取当前标签页、截取可见区域 |
| `scripting` | 必要时向当前页注入内容脚本以启动截图 |
| `<all_urls>` | 在任意网页注入内容脚本，实现选区捕获、单词高亮与感触高亮 |

## 开发

本项目为纯 JavaScript，无构建步骤。修改代码后，在扩展管理页点击扩展的 **重新加载** 即可生效。

回顾页和弹窗需在已加载的扩展环境中打开（通过扩展图标或 `review.html`），不能单独用静态服务器预览完整功能。
